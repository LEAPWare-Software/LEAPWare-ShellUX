7. **New shell-injection sink in a job holding `pull-requests: write`.** `.github/workflows/lwb-auto-queue.yml` interpolates `${{ github.event.inputs.pr }}` directly into a `run:` shell line rather than passing it through `env:`. `workflow_dispatch` inputs are free text; GitHub expands `${{ }}` before the shell parses the line, so a crafted input containing a quote and a semicolon executes arbitrary commands in that job's context, which carries `GH_TOKEN` and `pull-requests: write`. Every other `run:` interpolation in this repo's workflows uses event-controlled SHAs or integers, not free text — this is the one exception. Fix is mechanical: `env: PR: ${{ github.event.inputs.pr }}` and reference `"$PR"` in the script invocation.
