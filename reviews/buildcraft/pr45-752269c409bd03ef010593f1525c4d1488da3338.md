### CONFIRMED 5 (non-blocking, policy). The exemption still covers files of any type, at any depth, under `reviews/<pr>/`
```
['reviews/45/sub/payload.sh'] -> pr45: True
['reviews/45/notes.txt'] -> pr45: True
['reviews\45\x.json'] -> pr45: True
```
`independent_reviews` only globs `reviews/<pr>/*.json`, non-recursively (`lwb_lanes.py:768`). Any git identity can land these files. They are skipped by `lwb_check_commit_identity`, and they do not advance the reviewable head. The same identity can also rewrite `proof/45.json` or another reviewer's record without staling anything. This is narrower than main's `reviews/` or `proof/` rule, so it is not a regression — it is still a door the docs do not describe.
