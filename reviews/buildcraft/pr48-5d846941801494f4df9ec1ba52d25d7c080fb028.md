**F3 (confirmed): the regression test can be defeated by a mutant that reproduces
the exact bug it exists to catch.**
```
SHIPPED (rc=0; ... || rc=1 ...; exit "$rc")           -> TEST PASSES (correct)
OLD 3-line body (no || at all)                        -> TEST FAILS  (correct)
MUTANT: `... || true` (rc initialized, never set)     -> TEST PASSES  <-- gap
```
The test only checks that every `auto_queue.py`-invoking line contains `"||"`
and that `exit "$rc"`/`exit $?` appears somewhere in the run text; it never
checks the `||` clause actually assigns `rc` from the real exit status. A
future edit to `... || true` (silently swallow every PR's failure, step always
exits 0) would pass this test untouched — defeating exactly the "still fails
overall if any PR errored" half of its own docstring. The currently shipped
YAML does not have this defect (it correctly writes `|| rc=1`), so this is a
test-robustness gap, not a shipped-code defect — but it means the claimed
protection against a regression of this exact kind is weaker than stated.

## Held up

- Bash semantics: `rc=0; for pr in ...; do auto_queue.py || rc=1; done; exit "$rc"` — a command on the left of `||` is exempt from `set -e`'s abort (standard POSIX/bash), so PR #1 failing does not kill the loop; `rc` still accumulates; the step still exits nonzero overall. Matches the shape of the embedded prior reviewer's own `bash -e` execution probe (not independently re-run here, see Not checked).
- `auto_queue.py`'s exit-code design is safe for the loop's binary `rc` treatment: `EXIT_ENQUEUED=0`, `EXIT_NOT_READY=0`, `EXIT_ERROR=1` for every genuine-problem path. All ordinary-failure cases collapse to the same code, so the loop can't tell which case fired from the exit code alone, but it never masks a real problem as success and never treats "not ready yet" as failure. Per-PR detail is still recoverable from each `::group::PR #$pr` fold in the Actions log.
- `.github/workflows/auto-queue.yml` parses as valid YAML (`python3 -c "import yaml; yaml.safe_load(open(...))"` succeeds).
