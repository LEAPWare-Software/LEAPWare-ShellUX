  (`01WitrMM4pi6s1fGLHBECwKY`) resolves to a real, separate session:
  "BuildCraft independent reviewer B (newest-first)", `origin:

- Every commit in this repo is required to carry the same git author
  identity (owner directive 10, enforced by
  `scripts/lwb_check_commit_identity.py`), so git authorship alone cannot
  distinguish a reviewer commit from an author commit — this is a property

worth restating here because it is the honest reason this routine's initial
