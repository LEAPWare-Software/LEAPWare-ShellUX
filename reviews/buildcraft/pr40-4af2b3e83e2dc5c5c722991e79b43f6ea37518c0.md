### F6 — NEW. The `LWB-Agent: human` self-exemption from review is itself a guardrail, not an integrity control, and nothing tests it.

`TRAILER_RE` is `re.compile(r"^LWB-Agent:\s*(claude|codex|human)\s*$", re.MULTILINE)` applied via `.search()` to the whole commit body (`%B`), not to
git's structured trailer block, and `commit_agent` returns the first match.
A `human` line placed anywhere in the message wins over a later `claude`
line:

```

Real: LWB-Agent: claude"      # commit modifies scripts/lwb_lanes.py
```

Pre-existing, so not charged as a defect *introduced by* this PR — but this

gate rewrite should be allowed to use this exemption at all is an owner
call and is not charged here, but it should be named a guardrail explicitly
and given a test.
