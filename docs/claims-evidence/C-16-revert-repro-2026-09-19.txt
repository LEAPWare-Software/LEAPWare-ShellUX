C-16 manual reproduction, 2026-09-19 (proof audit item 22)
============================================================

Why manual: claims.yml (the environment the registered checks run in) installs no
Playwright browser (grep -n -i "playwright|chromium|browser" .github/workflows/claims.yml
is empty), so a `repo`-class probe that runs `npx playwright test` inside a scratch
worktree during `prove-claims.mjs` would fail there regardless of the chart fix's own
correctness. This file is the raw, one-off reproduction instead, run locally where
Chromium *is* installed (Playwright 1.63.0; `npx playwright --version`).

Method
------
1. `git worktree add --detach C:\Users\manny.ramos\leapware-hq\.workspaces\c16-repro 1248f02`
   (1248f02 = the merge commit of PR #148, "repairs #112, #113; addresses #111").
2. `node_modules` symlinked in from the main tree (no reinstall).
3. Baseline: `npx playwright test e2e/chart.spec.ts --reporter=list` at 1248f02, unmodified.
4. Revert: `git checkout 1248f02^1 -- src/core/chart/echartsRenderer.ts src/components/chart/Chart.tsx`
   (1248f02^1 = a59c15f, the commit immediately before the fix).
5. Mutated: `npx playwright test e2e/chart.spec.ts --reporter=list` again.
6. Restore: `git checkout 1248f02 -- src/core/chart/echartsRenderer.ts src/components/chart/Chart.tsx`,
   then re-ran the suite a third time to confirm the restore was exact (5 passed again).
7. `git worktree remove --force` the scratch worktree.
